# 모두가 살기 좋은 세상 만들기 · 자유 선택 버전

index.html을 열고 통합앱 시작을 누른 뒤 상단에서 원하는 게임을 선택하세요.

- 버블을 완료하지 않아도 테트리스를 시작할 수 있습니다. 테트리스에는 연대·협력·상생 각 10개와 시작 자본 300이 제공됩니다.
- 테트리스를 완료하지 않아도 가치전달을 시작할 수 있습니다. 가치전달에는 취약계층 지원·우범지대 개선·지역경제 활성화 각 3건이 제공됩니다.
- 각 게임의 기록과 자원을 별도로 저장합니다. 가치전달용 제공 가치가 테트리스 완료로 처리되지 않습니다.
- 게임을 바꾸면 현재 판은 종료되며 저장된 게임별 기록은 유지됩니다. 게임 안의 전체 초기화는 세 게임을 모두 초기화하고 시작용 자원을 다시 제공합니다.

## GitHub Pages 배포 준비
이 폴더의 내용물을 저장소 최상위에 올릴 수 있도록 상대 경로로 구성했습니다. index.html, 세 게임 HTML, fox_character_model.js, assets 폴더의 위치를 유지하세요. 별도 빌드나 설치가 필요 없습니다.

이 폴더를 만드는 과정에서 GitHub 업로드·배포는 실행하지 않았습니다. 자동 배포 워크플로도 포함하지 않습니다. 추후 배포하려면 저장소 Settings → Pages에서 브랜치와 /(root)를 직접 선택하세요.

소개 영상은 25MB가 넘으므로 GitHub 웹 업로드 대신 Git으로 폴더 전체를 추가할 수 있습니다. 로컬 실행은 index.html을 열면 됩니다.
